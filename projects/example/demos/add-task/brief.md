# add-task

## Audience

Someone who installed demorec and wants to see that it works.

## Goal

The viewer sees that a new task appears in the list and can be found with the filter.

## Story

The operator opens the task list, creates a task for themselves and filters the list to open
tasks.

## Key moments

1. Task list: the three demo tasks are visible
2. New task: the dialog is filled in with title, owner and due date
3. Task created: the new task is the first row and the confirmation is visible
4. Open tasks: the list shows only open tasks, including the new one

## Do not show

The Reports link, it leads nowhere.

## Format

About 20 seconds, 1280x720 browser (2560x1440 video), `add-task.mp4`.
